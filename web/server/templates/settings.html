Browser storage

The service worker caches a handful of small static files (CSS/JS/icons) for faster repeat loads — never card data or job status, which always come from the live server. If a page ever looks stuck on an old version after a deploy, use this instead of an ordinary reload: on an installed (Home Screen) app, a plain reload can still serve files the service worker cached, since it isn't the same thing as clearing Safari's cache.
